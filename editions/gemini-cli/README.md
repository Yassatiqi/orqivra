# Gemini CLI edition

Canonical skills are stored under `skills/`. The native `.gemini/skills/<skill-name>/SKILL.md` tree is generated by `orqivra install --edition gemini-cli --target PATH` or `orqivra build --edition gemini-cli --output DIR`; it is not duplicated in this source directory. Review the dry run and pass `--apply` to write. Inspect discovery with `/skills list` and refresh with `/skills reload`. Skill discovery does not by itself prove activation.

The Gemini model profile contains unresolved sample values. It specifies no reasoning-effort equivalent and does not change the active Gemini CLI model. Workspace trust, activation consent, policy, and tool confirmations determine access.

Official client guidance: [Gemini CLI skills](https://geminicli.com/docs/cli/tutorials/skills-getting-started/), [Managing Agent Skills](https://geminicli.com/docs/cli/using-agent-skills/).

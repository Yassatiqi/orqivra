# Codex edition

Canonical skills are stored under `skills/`. The native `.agents/skills/` tree is generated by `orqivra install --edition codex --target PATH` or `orqivra build --edition codex --output DIR`; it is not duplicated in this source directory. Install defaults to dry-run. Review the planned files, then pass `--apply` to write. Installation records owned files in a manifest and refuses modified collisions. Discover skills with `/skills` and invoke one explicitly by its `$orqivra-*` name. This package does not include `agents/openai.yaml`.

The `profiles/codex.json` file provides a sample role configuration. Its model identifiers and effort values have not been qualified in the target runtime. A profile is not a model switch or runtime compatibility claim. Codex sandbox and approval controls determine actual actions.

Official client guidance: [Codex skills](https://developers.openai.com/codex/skills).

# Claude Code edition

Canonical skills are stored under `skills/`. The native `.claude/skills/<skill-name>/SKILL.md` tree is generated by `orqivra install --edition claude-code --target PATH` or `orqivra build --edition claude-code --output DIR`; it is not duplicated in this source directory. Review the dry run and pass `--apply` to write. In an interactive session, inspect available skills with `/skills` and invoke a skill as `/orqivra-orchestrate`, `/orqivra-architecture`, `/orqivra-verify`, or `/orqivra-recover`. Workspace trust and configured settings can affect whether project skills load.

The Claude model profile contains unresolved sample values. It does not change the active Claude Code model. Permission prompts and configured tool rules remain authoritative.

Official client guidance: [Claude Code skills](https://code.claude.com/docs/en/skills).

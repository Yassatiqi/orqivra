# Change Log

## 0.3.0 - 2026-10-13

- Added versioned project configuration defaults, strict schema, and catalog-linked profiles for Codex, Claude Code, and Gemini CLI.
- Added catalog-backed model recommendations while keeping activation advisory and client-controlled; preserved all existing Codex profile choices.
- Documented config discovery, inheritance, null reasoning, custom model qualification, advisory parallelism, and client-native routing/fallback limitations.
- Kept Python and Node runtimes independent and packaged their defaults, schemas, and model catalog.
- Left client activation, Python 3.11 Windows junction qualification, GitHub Actions observation, registry ownership, and private reporting unresolved where not exercised.

## 0.2.0 - 2026-10-12

- Corrected cross-runtime root-boundary checks, regular-file input handling, and strict JSON Unicode validation.
- Aligned hypothesis normalization and installation manifest validation; immediate ownership checks reduce but do not eliminate filesystem race windows.
- Documented the Node validator's supported schema subset, independent runtime guarantees, client qualification limits, and truthful external publication checklist.
- Added runnable disposable quickstarts and preserved local release history outside the public documentation tree.
- Added an independent TypeScript CLI and installable npm distribution alongside the Python CLI.
- Added strict shared JSON parsing, canonical JSON hashing, interoperable DAG/state/evidence formats, and cross-runtime state support.
- Moved shared skill procedures to canonical sources and added validated client adapters with generated edition assets.
- Added npm bundles and safe manifest-scoped skill installation, verification, and removal.
- Added Python wheel and source distribution resources for pipx installation.
- Added compatibility, security, installation, contribution, and release documentation plus read-only Windows/Linux CI.
- Kept client and model runtime qualification separate from static validation and packaging checks.

## 0.1.0 - 2026-10-10

- Introduced provider-neutral orchestration, architecture, verification, and recovery contracts.
- Added Codex, Claude Code, and Gemini CLI skill editions and model profile samples.
- Added the local DAG, state, attempt, evidence, recovery, report, build, install, verify, and uninstall CLI.
- Added JSON Schemas, examples, acceptance tests, and an optional MIP external-validation adapter.
